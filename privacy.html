Privacy policy

Last updated: 25 October 2026.

pods-rclone is a private tool used by one person, the developer, to copy files between the developer's computers and one folder in the developer's Google Drive.

What the tool accesses

The tool signs in to the developer's own Google account and uses the Google Drive API to list, read and write files. It works only with the files the developer puts into it (simulation inputs and renders). It does not read email, contacts or any other Google data.

What is stored, and where

The sign-in token that Google issues stays in a configuration file on the developer's own computers. The files themselves stay in the developer's Google Drive and on the developer's computers. Nothing is stored on this website; this website consists of two static pages.

What is shared

Nothing is sold, shared with or transferred to anyone else. The tool has no servers of its own, no analytics, no advertising and no cookies. Because only the developer uses it, no data of other people is collected.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact and deletion

Questions: dattabotter@gmail.com. Access can be withdrawn at any time in the Google account's security settings (third-party access), which makes the stored token useless.
